# CHOIR

CHOIR is the research and specification workspace for the YUKTI project.

The current repository state treats CHOIR artifacts as provisional. The
manifesto explicitly frames the computational ontology as non-authoritative and
asks for criteria that can judge future ontology candidates. Implementation
work should therefore depend only on accepted specifications, not on inferred
meaning from empty placeholder files.

## Directory Intent

- `ontology/`: Notes about computational-universe boundaries, primitive
  validation, and relationship validation.
- `research/`: Research tracks that develop criteria and supporting arguments.
- `specifications/`: Accepted or proposed specification documents.
- `proposals/`: Proposal packages with assumptions, critiques, and status.
- `papers/`: Longer-form research outputs.

## Contribution Guidance

Document the reasoning behind each proposed ontology change before adding
implementation dependencies. If multiple interpretations remain valid, keep
them visible instead of collapsing them into one unstated assumption.
