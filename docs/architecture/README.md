# Architecture Notes

This directory records architecture documentation and decision-required notes.

Implementation work may update this directory when progress depends on a
choice that is not already specified. A decision note should describe the
decision, available options, tradeoffs, and recommendation, then stop until an
architect approves the direction.

## Decision Note Template

Use this structure when implementation is blocked by an architectural choice:

```markdown
# Decision Required: <short title>

## Decision

State the unresolved architecture decision.

## Options

Describe each viable option without changing specifications.

## Tradeoffs

Compare stability, complexity, testing impact, and future maintenance.

## Recommendation

Recommend one option and explain why.

## Approval Status

Pending architect approval.
```
